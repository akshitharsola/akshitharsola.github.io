Engineering Practice & CI

The repository's GitHub Actions workflow runs on every push and pull request to main via GitHub Actions (.github/workflows/ci.yml). It runs two jobs against this repository:

  • Lint Configuration and Workflows (lint): Sets up Python 3.11, installs yamllint, and validates workflow definitions and _config.yml.
  • Build Jekyll Site (build): Sets up Ruby 3.3 with Bundler caching and runs bundle exec jekyll build and fails the check if the site does not build.

Scope note: This repository contains no ROS 2 code, so the workflow has no colcon job.

{% highlight yaml %} --- name: CI "on": push: branches: - main pull_request: branches: - main jobs: lint: name: Lint Configuration and Workflows runs-on: ubuntu-latest steps: - name: Checkout repository uses: actions/checkout@v4 - name: Set up Python uses: actions/setup-python@v5 with: python-version: "3.11" - name: Install yamllint run: pip install yamllint - name: Run yamllint run: >- yamllint -d '{extends: default, rules: {line-length: disable, document-start: disable, braces: {max-spaces-inside: 1}}}' .github/ _config.yml build: name: Build Jekyll Site runs-on: ubuntu-latest steps: - name: Checkout repository uses: actions/checkout@v4 - name: Set up Ruby uses: ruby/setup-ruby@v1 with: ruby-version: "3.3" bundler-cache: true - name: Build site with Jekyll run: bundle exec jekyll build {% endhighlight %}
